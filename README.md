# Учебный репозиторий для обучения

## Назначение репозитория

Репозиторий содержит учебные материалы, домашние и лабораторные работы,
проектные и контрольные задания в рамках следующих дисциплин:

- МДК 02.07 Разработка программных модулей
- МДК 02.08 Поддержка и тестирование программных модулей
- МДК 03.01 Основы программирования на языке С++
- МДК 03.02 Объектно-ориентированное программирование с использованием языка C++
- МДК 04.02 Программирование с использование технологии Java и СУБД Oracle
