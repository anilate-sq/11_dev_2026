## Как пользоваться

1. Выберите дисциплину в таблице выше.
2. Откройте нужное занятие по ссылке в оглавлении дисциплины.
3. Изучите `README.md`, разберите демонстрационные примеры и выполните практику или домашнее задание.
4. Размещайте собственные решения в **своём GitHub-репозитории** и сдавайте ссылку способом, указанным преподавателем.

Для локального чтения примеров можно получить актуальную ветку:

```bash
git clone --branch dev https://github.com/anilate-sq/11_dev_2026.git
```

> Этот репозиторий — источник учебных материалов, а не место сдачи работ. Команда `git push` здесь не требуется: свои изменения отправляйте в личный репозиторий.

## Единый принцип организации

- **Корневой README** — навигация между дисциплинами.
- **README дисциплины** — оглавление курса и правила работы.
- **README занятия** — теория или описание задания.
- **`demo/`** — демонстрационный код (если предусмотрен).
- **`practice/`** — материалы и задания для работы на занятии.
- **`homework/`** — домашнее задание (при наличии).

Состав папок может отличаться в зависимости от дисциплины и темы: отсутствующие папки не создаются только ради шаблона.
