# Домашнее задание

## Цель

Закрепить умение создавать и запускать Java-файлы, а также поработать с Git.

## Задание

Напишите программу, которая выводит в консоль короткий рассказ о прошедшем дне (5–7 предложений). Каждое предложение — отдельный вызов `System.out.println`. Темы предложений можно выбрать любые: учёба, друзья, увлечения.

## Требования

- Имя класса — `Main`, имя файла — `Main.java`.
- Программа запускается командой `java Main.java` без компиляции вручную.
- Никаких технологий, кроме `System.out.println`, использовать не нужно.

## Что необходимо предоставить

- Исходный код в `homework/` вашей личной копии репозитория.
- Один commit с сообщением, описывающим, что сделано.
- Ссылку на commit при сдаче.
