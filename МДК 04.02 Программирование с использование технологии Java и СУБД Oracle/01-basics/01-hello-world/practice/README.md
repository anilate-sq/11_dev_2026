# Практическая работа № 1

## Тема

Hello World. Знакомство со структурой Java-программы.

## Цель работы

Научиться создавать Java-файл в VS Code, компилировать и запускать программу из терминала.

## Задание

Напишите программу «Моя визитка». Программа должна выводить в консоль:

1. ваше имя;
2. ваш возраст;
3. группу, в которой вы учитесь;
4. фразу о том, почему вы выбрали программирование.

Каждый пункт — отдельная строка. Используйте `System.out.println`.

## Требования

- Имя класса — `Main`, имя файла — `Main.java`.
- Программа запускается командой `java Main.java`.
- Каждый текст выводится в отдельной строке.
- Не используйте кириллические буквы в именах классов.

## Формат результата

- Код, сохранённый в `practice/Main.java`.
- Изменения зафиксированы в Git (один commit с понятным сообщением).
