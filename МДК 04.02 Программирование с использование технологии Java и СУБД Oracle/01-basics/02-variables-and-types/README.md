# Переменные и типы данных

## Цель занятия

Научиться хранить данные в переменных, выбирать правильный тип и выполнять простые арифметические операции.

## Что сегодня изучаем?

- что такое переменная и тип данных;
- целые и дробные числа: `int`, `double` (и их родственники);
- логический тип `boolean` и символы `char`;
- строки `String`;
- объявление, инициализация и изменение переменных;
- арифметические операции `+`, `-`, `*`, `/`, `%`;
- константы через `final`;
- простое преобразование типов.

## Основная терминология

| Термин | Определение |
| ------ | ----------- |
| Variable | Именованное хранилище значения в памяти программы |
| Тип данных | Правило, какие значения и операции допустимы для переменной |
| Declaration | Объявление переменной: указание типа и имени |
| Initization | Присвоение переменной начального значения |
| Literal | Явно записанное значение в коде: `17`, `89.90`, `"привет"` |
| Constant | Значение, которое нельзя изменить после присвоения (`final`) |
| Casting | Явное преобразование значения из одного типа в другой |

## Теория

Переменная — это именованное хранилище: вы даёте значению имя и дальше работаете с ним, а не с самим «сырым» числом. У каждой переменной есть тип — он определяет, что можно в неё положить и какие операции с ней допустимы. Нельзя просто сложить текст и число или записать дробь в переменную для целых чисел — Java за этим следит.

В базовых темах используются основные типы:

| Тип | Что хранит | Пример |
| --- | ---------- | ------ |
| `int` | целые числа | `17` |
| `double` | числа с дробной частью | `89.90` |
| `boolean` | истина или ложь | `true` |
| `char` | один символ | `'А'` |
| `String` | строка текста | `"Java"` |

Кроме `int` бывают `byte`, `short`, `long` для чисел разного размера, кроме `double` — `float`. На начальном этапе они вам почти не понадобятся.

Имена переменных пишутся в стиле `camelCase`: первое слово с маленькой буквы, следующие — с заглавной: `customerName`, `totalPrice`.

## Базовый синтаксис

```java
int age = 17;                 // целое число
double price = 89.90;         // число с дробной частью
boolean isActive = true;      // истина или ложь
char group = 'А';             // один символ в одинарных кавычках
String name = "Мария";        // строка в двойных кавычках

final double RATE = 92.5;     // константа: изменить нельзя

age = 18;                     // смена значения
```

- Слева от `=` — тип и имя, справа — значение.
- У `String`, `char` и `double` разные «кавычки»: `"..."` для строк, `'...'` для одного символа. Это разные типы, путать их нельзя.
- `final` делает значение неизменяемым. Имена констант пишут ЗАГЛАВНЫМИ буквами.
- Тип указывается только при объявлении. Дальше переменная используется по имени просто так: `age = 18;`

## Практические примеры

### Пример 1. Профиль пользователя

```java
public class Main {
    public static void main(String[] args) {
        String name = "Мария";
        int age = 17;
        double height = 165.5;
        char group = 'А';
        boolean likesJava = true;

        System.out.println("Имя: " + name);
        System.out.println("Возраст: " + age);
        System.out.println("Рост: " + height + " см");
        System.out.println("Группа: " + group);
        System.out.println("Нравится Java: " + likesJava);
    }
}
```

Вывод:

```
Имя: Мария
Возраст: 17
Рост: 165.5 см
Группа: А
Нравится Java: true
```

Одна переменная — одна сущность. Мы объявили пять переменных: каждая хранит свой «факт» о пользователе. Знак `+` здесь склеивает текст и значение: Java сама превращает число в строку для вывода.

### Пример 2. Расчёт чека в магазине

```java
public class Main {
    public static void main(String[] args) {
        final double PRICE_MILK = 90.0;
        final double PRICE_BREAD = 50.0;

        int milkCount = 2;
        int breadCount = 1;

        double milkTotal = PRICE_MILK * milkCount;
        double breadTotal = PRICE_BREAD * breadCount;
        double total = milkTotal + breadTotal;

        System.out.println("Молоко: " + milkTotal + " руб.");
        System.out.println("Хлеб: " + breadTotal + " руб.");
        System.out.println("Итого: " + total + " руб.");
    }
}
```

Вывод:

```
Молоко: 180.0 руб.
Хлеб: 50.0 руб.
Итого: 230.0 руб.
```

Цены не должны меняться внутри программы — поэтому `final` и ЗАГЛАВНЫЕ имена. Количество товара целое (`int`), а стоимость результата дробная (`double`). Обратите внимание: Java не «теряет» число, когда умножает `double` на `int`.

### Пример 3. Конвертация валют

```java
public class Main {
    public static void main(String[] args) {
        double exchangeRate = 92.5;
        int dollars = 100;

        double rubles = dollars * exchangeRate;
        int fullRubles = (int) rubles;

        System.out.println(dollars + " USD = " + rubles + " руб.");
        System.out.println("Целыми рублями: " + fullRubles);
    }
}
```

Вывод:

```
100 USD = 9250.0 руб.
Целыми рублями: 9250
```

`(int) rubles` — это явное преобразование (casting): мы говорим Java «возьми значение и отбрось дробную часть». Обычно Java сама расширяет тип (`int` в `double`), но сужать (`double` в `int`) можно только явно.

## Разбор примера

Разберём пример 2 — он ближе всего к реальному коду.

- `final double PRICE_MILK = 90.0;` — константа. Цена товара не должна меняться во время работы программы, поэтому она `final`. Имя константы — ЗАГЛАВНЫМИ буквами, по соглашению.
- `int milkCount = 2;` — количество товара целое: в магазине не бывает «2.5 молока». Пока тип `int`, Java разрешит использовать в операции `double`: `PRICE_MILK * milkCount`, и результат будет `double`. Это безопасное расширение типа.
- `double total = milkTotal + breadTotal;` — итог дробный, потому что рубли бывают с копейками.
- `System.out.println("Молоко: " + milkTotal + " руб.");` — `+` склеивает текст, число и ещё текст. Java умеет превращать любое число в строку.

`+` работает по-разному в зависимости от окружения: если слева текст — это склейка, если слева число — это арифметика. Начинающие часто путаются, когда `2 + 3` вдруг становится `"23"`: `"Сумма = " + 2 + 3` склеит строку, а `2 + 3` просто вычислит `5`.

## Итоги занятия

- Переменная объявляется как `тип имя = значение;`.
- Основные типы: `int`, `double`, `boolean`, `char`, `String`.
- `final` создаёт константу, имя константы пишется ЗАГЛАВНЫМИ буквами.
- Арифметика: `+ - * / %`. Деление целых теряет дробную часть.
- `double` в `int` сужается только явно через `(int)`.
- Имена переменных — осмысленные, в стиле `camelCase`.
