# Домашнее задание

## Цель

Закрепить умение объявлять переменные разных типов и выполнять арифметические вычисления над ними.

## Задание

Напишите программу «План накоплений». Студент получает стипендию (или небольшую зарплату), платит за разные расходы и хочет накопить на смартфон.

Объявите переменные для ваших личных данных:

- стипендия за месяц (`int`);
- расходы за месяц по трём статьям: питание, проезд, развлечения (`int` каждая);
- цена смартфона, который хочется купить (`double`).

Посчитайте и выведите:

1. расходы за месяц (сумму трёх статей);
2. остаток за месяц (стипендия минус расходы);
3. накопления за полгода (остаток × 6);
4. через сколько полных месяцев стипендии удастся накопить на смартфон — используйте целочисленное деление;
5. фразу «хватит за X месяцев», где X — результат предыдущего пункта.

## Требования

- Используйте типы `int` и `double` там, где это уместно.
- Имена переменных осмысленные, в стиле `camelCase`.
- Комментарии объясняют сложные расчёты, а не очевидные строки.
- Программа компилируется и запускается командой `java Main.java`.
- Числа для расчёта — ваши, реальные; смартфон можно выбрать любой.
