# Домашнее задание

## Цель

Закрепить чтение ввода через `Scanner`, выбор типов данных и форматированный вывод.

## Задание

Напишите программу «Семейный бюджет на месяц». Программа спрашивает данные и считает:

1. Доход за месяц (целое число).
2. Расходы по трём статьям: питание, транспорт, развлечения (каждая — целое число).
3. Расчёт: общие расходы, остаток за месяц, средний расход в день (остаток делим — расходы делим на 30).
4. Сколько месяцев получится «протянуть» без дохода на текущие сбережения, если откладывать весь остаток (целочисленное деление остатка на расходы).

Вывод через `printf`: заголовки и все значения с двумя знаками после запятой для дробных сумм.

## Требования

- Используйте методы `nextInt()` и `nextDouble()` для ввода.
- Комментарии объясняют формулы расчёта, а не очевидные строки.
- Программа компилируется и запускается командой `java Main.java`.
- Числа — ваши реальные или разумно близкие к реальности.
