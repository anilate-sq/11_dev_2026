# Практическая работа № 3

## Тема

Ввод и вывод. Интерактивные программы.

## Цель работы

Научиться читать данные с клавиатуры через `Scanner` и выводить отформатированный результат через `printf`.

## Задание

Служба доставки «Роллинг Стоун» считает стоимость заказа. Напишите программу, которая:

1. Спрашивает имя клиента (строка).
2. Спрашивает количество роллов (целое) и цену одного ролла (дробное).
3. Спрашивает расстояние доставки в километрах (дробное).
4. Считает стоимость заказа по простым правилам:
   - роллы: количество × цена;
   - доставка: 149 руб. + 20 руб. за каждый километр;
   - итог: роллы + доставка.
5. Выводит чек через `printf`: имя клиента, позицию, доставку и итог — все денежные суммы с двумя знаками после запятой (`%.2f`).

Начните с заготовки `practice/Main.java` — в ней уже есть часть кода, допишите остальное.

## Требования

- Использованы методы `nextLine()`, `nextInt()`, `nextDouble()` — по одному на каждый тип данных.
- Вывод оформлен через `printf` с формат-спецификаторами `%s`, `%d`, `%.2f`.
- Строка с именем читается до числовых вводов.
- Сканер закрывается в конце программы.
- Программа компилируется и запускается командой `java Main.java`.

Пример работы:

```
Ваше имя: Артём
Сколько роллов: 3
Цена одного ролла: 149.50
Расстояние доставки, км: 5.5
Артём, ваш заказ:
Роллы x3 = 448.50 руб.
Доставка = 259.00 руб.
Итого к оплате: 707.50 руб.
```
