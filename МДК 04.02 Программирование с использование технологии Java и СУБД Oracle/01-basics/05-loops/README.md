# Циклы

## Цель занятия

Научиться автоматизировать повторяющиеся действия циклами `for`, `while` и `do-while`.

- цикл `for` со счётчиком;
- цикл `while` — повторение, пока условие истинно;
- цикл `do-while` — выполнение хотя бы один раз;
- инкремент `++` и шаг цикла;
- накопление суммы в цикле;
- поиск максимума в ряду чисел;
- операторы `break` и `continue`.

## Основная терминология

| Термин | Определение |
| ------ | ----------- |
| Цикл (loop) | Конструкция, повторяющая блок кода несколько раз |
| Итерация | Один проход тела цикла |
| Счётчик | Переменная, хранящая номер текущей итерации |
| Инкремент | Увеличение переменной на единицу: `i++` |
| Тело цикла | Блок кода `{ ... }`, который повторяется |
| Бесконечный цикл | Цикл, условие которого никогда не становится ложным |

## Теория

Одна и та же операция редко нужна один раз. «Выведи числа от 1 до 10», «суммируй месячные сбережения», «пока сумма не достигнет цели — добавляй» — всё это циклы.

Выбор цикла по ситуации:

- `for` — когда **заранее известно** число повторений (от 1 до N).
- `while` — когда повторяем **пока истинно условие** и заранее неизвестно, когда оно станет ложным.
- `do-while` — когда надо **гарантированно выполнить хотя бы один раз**, потом проверять условие.

Классическая ошибка — зацикленная программа, где забыли менять счётчик или условие. «Железное» правило: внутри тела цикла должно что-то меняться, что рано или поздно сделает условие ложным.

## Базовый синтаксис

```java
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; i++) {
            System.out.println("Итерация " + i);
        }
    }
}
```

Три части `for` читаются как: «начать с 1 (`i = 1`), крутить, пока `i <= 5`, на каждом шаге увеличивать (`i++`)».

```java
int i = 1;
while (i <= 5) {
    System.out.println("Итерация " + i);
    i++;
}
```

Тот же результат через `while`: счётчик объявлен снаружи, внутри тела он увеличивается.

```java
int i = 1;
do {
    System.out.println("Итерация " + i);
    i++;
} while (i <= 5);
```

`do-while` отличается порядком: сначала тело, потом проверка. Даже если `i` сразу больше 5, тело выполнится хотя бы один раз.

## Практические примеры

### Пример 1. Таблица умножения

```java
public class Main {
    public static void main(String[] args) {
        int number = 7;

        for (int i = 1; i <= 10; i++) {
            System.out.println(number + " x " + i + " = " + (number * i));
        }
    }
}
```

Вывод (первые строки):

```
7 x 1 = 7
7 x 2 = 14
...
7 x 10 = 70
```

Число повторений известно (10) — это чистый `for`.

### Пример 2. Копилка на смартфон

```java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Сколько откладываете в месяц: ");
        int monthly = scanner.nextInt();

        System.out.print("Сколько нужно накопить: ");
        int goal = scanner.nextInt();

        int total = 0;
        int months = 0;

        while (total < goal) {
            months++;
            total = total + monthly;
            System.out.println("Месяц " + months + ": накоплено " + total + " руб.");
        }

        System.out.println("Цель достигнута за " + months + " месяцев!");
        scanner.close();
    }
}
```

Сколько месяцев понадобится — заранее неизвестно, поэтому `while`. Пока `total < goal`, цикл добавляет месяц и сумму.

### Пример 3. Средняя температура за неделю с максимумом

```java
import java.util.Locale;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Locale.setDefault(Locale.US);

        Scanner scanner = new Scanner(System.in);

        double total = 0;
        double maxTemperature = -100;

        for (int day = 1; day <= 7; day++) {
            System.out.print("Температура в день " + day + ": ");
            double temperature = scanner.nextDouble();

            total = total + temperature;
            if (temperature > maxTemperature) {
                maxTemperature = temperature;
            }
        }

        double average = total / 7;
        System.out.println("Средняя температура: " + average);
        System.out.println("Максимум за неделю: " + maxTemperature);
        scanner.close();
    }
}
```

## Разбор примера

Разберём пример 2 — копилку.

- `int total = 0; int months = 0;` — аккумуляторы. В цикле они накапливают результат, поэтому инициализируются нулём до цикла.
- Условие `total < goal` — «пока цель не достигнута». Внутри тела обязательно меняется `total`, иначе условие никогда не станет ложным и цикл будет бесконечным.
- `months++` — то же самое, что `months = months + 1`.
- В примере 3 принцип «бегущего максимума»: `maxTemperature` стартует с очень маленького значения (`-100`), и каждое число сравнивается с текущим максимумом. Это универсальный приём поиска наибольшего значения.
- В `for (int i = 1; i <= 10; i++)` счётчик `i` живёт **только внутри цикла** — после `}` он недоступен.

## Итоги занятия

- `for` — известное число повторов, счётчик управляется в скобках.
- `while` — повторение, пока условие истинно.
- `do-while` — тело исполняется минимум один раз.
- Накопление суммы: аккумулятор до цикла, `+=` внутри.
- Максимум ищется сравнением каждого значения с текущим максимумом.
- Тело цикла обязано менять что-то, влияющее на условие.
