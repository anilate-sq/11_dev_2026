# Практическая работа № 5

## Тема

Циклы: `for`, `while`, `do-while`.

## Цель работы

Научиться применять циклы для накопления суммы, поиска максимума и работы с неизвестным числом повторов.

## Задание

Программа «Учёт расходов за неделю» анализирует траты за 7 дней.

1. Циклом `for` по дням спрашивайте расход за каждый из 7 дней.
2. Внутри цикла копите общую сумму и отслеживайте день с максимальным расходом.
3. После цикла выведите:
   - общую сумму за неделю;
   - средний расход в день (сумма / 7);
   - день с максимальным расходом и его сумму.
4. Дополнительно `while`/`do-while`: спросите «остаток цели» — программе нужно повторить вывод «До цели осталось X руб.», уменьшая X на средний расход, пока остаток больше 0. Посчитайте, сколько потребуется повторений.

Начните с заготовки `practice/Main.java`.

## Требования

- Использован `for` по дням.
- Поиск максимума — сравнение каждого значения с текущим максимумом, стартовое значение максимума заведомо меньше любого расхода.
- Для «остатка цели» — цикл `while` (или `do-while`), где условие становится ложным.
- Комментарии объясняют формулы, а не очевидные строки.
- Программа компилируется и запускается командой `java Main.java`.

Пример работы (расходы 200, 150, 300, 100, 250, 180, 210; цель 1000):

```
Расход за день 1: 200
Расход за день 2: 150
...
Сумма за неделю: 1390.0 руб.
Средний расход в день: 198.57 руб.
Максимум: день 3, 300.0 руб.
Цель: 1000.0 руб.
Остаток 801.43 руб.
Остаток 602.86 руб.
Остаток 404.29 руб.
Остаток 205.72 руб.
Остаток 7.15 руб.
Требуется повторений: 5
```
