# Методы. Объявление, параметры, возвращаемое значение

## Цель занятия

Научиться выделять повторяющиеся действия в отдельные методы, передавать в них данные через параметры и получать результат работы с помощью возвращаемого значения. Студент сможет самостоятельно написать программу, разбитую на небольшие методы.

## Что сегодня изучаем?

- Понятие метода в Java
- Зачем нужны методы и принцип DRY (не повторять код)
- Объявление метода `public static`
- Параметры метода и передача аргументов
- Возвращаемое значение, ключевое слово `return`
- Методы `void` и методы, возвращающие значение
- Вызов методов из `main`

## Основная терминология

| Термин | Определение |
| ------ | ----------- |
| Метод | Блок кода, который выполняет определённое действие и может быть вызван несколько раз |
| Объявление метода | Описание метода: имя, параметры, тип возвращаемого значения |
| Вызов метода | Выполнение кода, написанного внутри метода |
| Параметры | Данные, которые метод получает на вход для работы |
| Аргументы | Конкретные значения, передаваемые в метод при вызове |
| Возвращаемое значение | Результат работы метода, который он передаёт обратно в программу |
| `void` | Тип возвращаемого значения, означающий, что метод ничего не возвращает |

## Теория

Метод — это именованный блок кода, который решает отдельную задачу. Вместо того чтобы дублировать одно и то же действие несколько раз, его можно вынести в метод и вызывать по имени. Так код становится короче, понятнее и удобнее для исправлений.

У метода есть вход — параметры. Они позволяют передавать в метод разные значения, не переписывая его код. У метода может быть выход — возвращаемое значение. Если результат работы не нужен, метод объявляют с типом `void`.

Все методы в этом занятии будем объявлять как `public static`, так как они вызываются из статического метода `main`. Это соответствует текущему уровню изучения (без ООП).

## Базовый синтаксис

```java
public static типВозврата имяМетода(тип параметр1, тип параметр2) {
    // тело метода
    return значение;
}
```

- `типВозврата` — тип данных, который метод вернёт (например, `int`, `double`, `String`). Если ничего не возвращает — `void`.
- `имяМетода` — осмысленное название в camelCase (глагол или глагольное словосочетание).
- В круглых скобках указываются параметры (может быть пусто).
- `return` — возвращает результат из метода. Для `void`-метода `return` можно не писать.

Вызов метода из `main`:
```java
имяМетода(аргумент1, аргумент2);
```
Если метод возвращает значение, его можно сохранить в переменную:
```java
int результат = имяМетода(5, 3);
```

## Практические примеры

### Пример 1. Расчёт суммы заказа в кафе

Посчитаем стоимость позиции меню: цену умножаем на количество порций.

```java
public class Main {
    
    // Метод для расчёта суммы
    public static double calculateSum(double price, int quantity) {
        return price * quantity;
    }
    
    public static void main(String[] args) {
        double price = 250.0;
        int quantity = 2;
        double sum = calculateSum(price, quantity);
        System.out.println("Сумма заказа: " + sum + " руб.");
    }
}
```

### Пример 2. Проверка возраста покупателя

Проверим, может ли человек купить товар по возрастному ограничению.

```java
public class Main {
    
    // Метод проверяет, достаточно ли возраста
    public static boolean isAdult(int age) {
        return age >= 18;
    }
    
    public static void main(String[] args) {
        int age = 17;
        if (isAdult(age)) {
            System.out.println("Доступ разрешён");
        } else {
            System.out.println("Доступ ограничен");
        }
    }
}
```

### Пример 3. Вывод чека заказа

Разделим логику: расчёт — в методе с возвратом значения, вывод — в отдельном `void`-методе.

```java
public class Main {
    
    public static double calculateTotal(double price, int quantity) {
        return price * quantity;
    }
    
    public static void printReceipt(String itemName, double price, int quantity, double total) {
        System.out.println("Чек заказа:");
        System.out.println(itemName + " x " + quantity);
        System.out.println("Цена за 1 шт.: " + price + " руб.");
        System.out.println("Итого: " + total + " руб.");
    }
    
    public static void main(String[] args) {
        String itemName = "Чизбургер";
        double price = 350.0;
        int quantity = 2;
        double total = calculateTotal(price, quantity);
        printReceipt(itemName, price, quantity, total);
    }
}
```

## Разбор примера

В третьем примере логика разделена на два небольших метода. Метод `calculateTotal` отвечает только за расчёт суммы — он получает данные на вход и возвращает результат. Метод `printReceipt` отвечает только за вывод информации — он ничего не возвращает (`void`), но получает все данные для печати через параметры.

Такой подход упрощает чтение кода: в `main` мы видим последовательность действий, а детали расчёта и вывода спрятаны в именованных методах. Параметры позволяют использовать одни и те же методы с разными значениями, не меняя их код.

## Итоги занятия

- Метод помогает избежать дублирования кода и делает программу понятнее.
- Параметры передают данные в метод для обработки.
- Ключевое слово `return` возвращает результат работы метода.
- Метод с `void` ничего не возвращает, а просто выполняет действия.
- Разделение задач по методам упрощает поддержку кода.
