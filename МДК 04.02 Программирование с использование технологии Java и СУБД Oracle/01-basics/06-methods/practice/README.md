# Практическая работа № 6

## Тема

Методы. Объявление, параметры, возвращаемое значение

## Цель работы

Научиться создавать методы с параметрами, возвращать значение из метода, а также использовать `void`-методы для вывода информации.

## Задание

Разработать программу «Калькулятор заказа». Программа должна считать сумму покупки по цене и количеству товара, а также выводить подробный чек на экран.

## Требования

- Создать метод `calculateSum(double price, int quantity)`, который принимает цену и количество товара и возвращает сумму покупки.
- Создать метод `printReceipt(String productName, double price, int quantity, double total)`, который выводит чек на экран.
- В методе `main` считать с клавиатуры название товара, цену за 1 шт. и количество.
- Вызвать методы для расчёта и вывода чека.
- Использовать `Locale.setDefault(Locale.US)` для корректного ввода/вывода дробных чисел.
- Класс `Main`, программа запускается через `java Main.java`.

## Пример работы программы

```
Введите название товара: Кофе
Введите цену за 1 шт.: 250.0
Введите количество: 2
=== ЧЕК ЗАКАЗА ===
Товар: Кофе
Цена за 1 шт.: 250.0 руб.
Количество: 2
Итого к оплате: 500.0 руб.
==================
```

## Формат результата

- Готовый, компилирующийся код в файле `practice/Main.java`
- Программа должна корректно обрабатывать введённые данные
