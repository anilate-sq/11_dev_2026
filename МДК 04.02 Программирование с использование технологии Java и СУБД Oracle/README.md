# Разработка на Java

Учебный репозиторий курса «Разработка на Java». Весь учебный материал находится прямо здесь — в виде Markdown-файлов и Java-кода.

Репозиторий одновременно является:

- учебной методичкой;
- набором демонстрационных примеров;
- практикумом;
- хранилищем исходного кода;
- местом для домашних работ;
- историей вашего обучения через Git.

## Как работать с репозиторием

### 1. Клонировать репозиторий

```bash
git clone <адрес репозитория>
```

### 2. Открыть в VS Code

```bash
cd java-course
code .
```

### 3. Найти нужную тему

Все темы разбиты на блоки: `01-basics`, `02-oop`, `03-collections` и так далее. Внутри каждого блока — нумерованные папки тем, например `01-basics/03-input-and-output`.

В каждой теме:

| Папка       | Что находится                                             |
| ----------- | --------------------------------------------------------- |
| `README.md` | учебный материал занятия                                  |
| `demo/`     | код, который разбираем вместе на занятии                  |
| `practice/` | самостоятельная работа на занятии                         |
| `homework/` | домашнее задание (без готового решения)                   |

### 4. Запускать Java-программы

Если код написан в `demo/Main.java`:

```bash
cd demo
java Main.java
```

Команда `java Main.java` запускает программу напрямую (Java 11 и новее). Если она не работает — сначала скомпилируйте:

```bash
javac Main.java
java Main
```

### 5. Сохранять изменения через Git

В начале занятия ваша папка `demo/` уже содержит код, который мы пишем вместе. Не бойтесь экспериментировать — Git всегда позволит вернуться к прошлой версии.

### 6. Делать commit

```bash
git add .
git commit -m "Тема: переменные и типы данных"
```

Пишите понятные сообщения: они станут историей вашего обучения.

### 7. Отправлять изменения в GitHub

```bash
git push
```

Полезные команды для проверки состояния:

```bash
git status
git log --oneline
```
