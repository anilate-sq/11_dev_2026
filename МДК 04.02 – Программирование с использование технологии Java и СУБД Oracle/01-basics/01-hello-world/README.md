# Hello World

## Цель занятия

Написать первую программу на Java, понять, как она устроена, и научиться запускать её через консоль и VS Code.

## Что сегодня изучаем?

- что такое Java-файл и почему у файла есть имя;
- что такое метод `main`;
- как вывести текст в консоль;
- как Java-программа скомпилировать и запустить;
- что такое `class` на минимальном примере.

## Основная терминология

| Термин | Определение |
| ------ | ----------- |
| Source file | Текстовый файл с Java-кодом, расширение `.java` |
| Class | Базовый строительный блок программы на Java; имя класса обязательно совпадает с именем файла |
| Method | Поименованный блок кода; программа начинает выполнение с метода `main` |
| Statement | Отдельная выполняемая команда; в Java заканчивается точкой с запятой `;` |
| Console | Окно терминала, куда программа выводит текст |

## Теория

Java-программа — это набор файлов с расширением `.java`. Внутри каждого файла описывается класс. Java позволяет запускать только те файлы, в которых есть метод `main` — именно с него начинается выполнение программы.

Подход к обучению: мы пишем код, запускаем его, видим результат в консоли и постепенно усложняем. Все файлы этой темы вы можете открыть в VS Code и запустить.

## Базовый синтаксис

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Привет, мир!");
    }
}
```

- `public class Main` — объявление класса с именем `Main`. Имя файла обязано совпадать с именем класса: `Main.java`.
- `public static void main(String[] args)` — точка входа в программу. Строка выглядит страшно, но её достаточно просто копировать каждый раз, когда начинаете новую программу.
- `System.out.println("...")` — команда вывода строки в консоль.
- `;` — команда закончена.

## Практические примеры

### Пример 1. Классический Hello World

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

Запуск:

```bash
java Main.java
```

### Пример 2. Постепенное усложнение

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Меня зовут Алексей.");
        System.out.println("Я учусь программировать на Java.");
        System.out.println("Сумма 2 + 3 равна " + (2 + 3));
    }
}
```

`+` соединяет текст и число. Java сама превратит результат вычисления `(2 + 3)` в текст.

### Пример 3. Программа, использующая данные извне

```java
public class Main {
    public static void main(String[] args) {
        if (args.length > 0) {
            System.out.println("Привет, " + args[0] + "!");
        } else {
            System.out.println("Привет, незнакомец!");
        }
    }
}
```

Запуск с передачей аргумента — имя попадёт в вывод:

```bash
java Main.java Мария
```

Вывод:

```
Привет, Мария!
```

## Разбор примера

- Программа всегда начинается с `main`. Пока мы воспринимаем строку с `main` как обязательный «каркас» и не обращаем внимания на детали вроде `static` — до них дойдём в блоке про ООП.
- `System.out.println(...)` каждый раз печатает новую строку. В третьем примере мы видим, что код может реагировать на входные данные: `args` — это массив переданных при запуске строк.
- Типичная путаница новичка: имя файла `Main.java` и имя класса `Main` должны совпадать точно, включая заглавные буквы. Java регистрозависима — `main` и `Main` это разные слова.

## Итоги занятия

- Java-программа — это файл `.java` с классом и методом `main`.
- Метод `main` — точка входа, с него начинается выполнение.
- `System.out.println(...)` выводит строку в консоль.
- Команды отделяются точкой с запятой `;`.
- Имя файла должно совпадать с именем класса.
