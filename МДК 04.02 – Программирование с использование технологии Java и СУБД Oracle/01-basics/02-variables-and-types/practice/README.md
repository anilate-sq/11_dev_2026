# Практическая работа № 2

## Тема

Переменные и типы данных.

## Цель работы

Научиться объявлять переменные разных типов, выбирать правильный тип под данные и выполнять арифметические расчёты.

## Задание

Кафе «Бариста» принимает заказ. Цены в меню фиксированные, количество блюд выбираете вы.

| Блюдо | Цена |
| ----- | ---- |
| Капучино | 149 руб |
| Круассан | 99 руб |
| Сэндвич | 199 руб |
| Скидка по карте лояльности | 10% |

Напишите программу, которая:

1. Объявляет цены блюд как константы (`final`).
2. Объявляет количество каждого блюда целыми числами.
3. Вычисляет стоимость каждой группы блюд и общую сумму заказа.
4. Вычисляет размер скидки и итоговую сумму к оплате.
5. Выводит в консоль чек: название кафе, позиции с ценой и количеством, сумму до скидки, размер скидки, итог.

Начните с заготовки `practice/Main.java` — в ней объявлены исходные данные, вам нужно дописать расчёты и вывод.

## Требования

- Все источники данных объявлены как переменные, в коде нет «магических» чисел, кроме исходных цен.
- Использованы как минимум типы: `final double`, `int`, `String`.
- Имена переменных осмысленные и в стиле `camelCase`, константы — ЗАГЛАВНЫМИ буквами.
- Программа компилируется и запускается командой `java Main.java`.
- Вывод соответствует примерному виду:

```
Кафе «Бариста»
Капучино x1 = 149.0 руб.
Круассан x2 = 198.0 руб.
Сэндвич x1 = 199.0 руб.
Сумма до скидки: 546.0 руб.
Скидка: 54.6 руб.
Итого к оплате: 491.4 руб.
```

## Формат результата

- Исходный код в `practice/Main.java`.
- Изменения сохранены в Git: один commit с понятным сообщением.
