# Домашнее задание

## Цель

Закрепить работу с условиями и `switch` на реальной задаче — «домашний банк».

## Задание

Напишите программу «Домашний банк». Начальный баланс на счёте — 10000 руб. (константа). Программа показывает меню и выполняет действие:

```
1 — Показать баланс
2 — Пополнить счёт
3 — Снять наличные
4 — Добавить проценты (0,5% в месяц)
0 — Выход
```

Что должно работать:

- Меню построено на `switch`. Для неизвестного пункта — сообщение и возврат к меню (предложите: можно обернуть всё в `do-while` из следующей темы или сделать повторный вызов через цикл, которого вы ещё не проходили, — в таком случае просто выведите предупреждение и завершите программу).
- Пункт «Снять наличные»: запросить сумму и проверить условием `if` — хватает ли денег. Если не хватает, вывести отказ и НЕ менять баланс.
- Пункт «Проценты»: прибавить к балансу `balance * 0.005`.
- После каждого действия выводить актуальный баланс с двумя знаками (`printf` `%.2f`).
- Проверка «ввода отрицательной суммы» в операциях пополнения и снятия — через `if`.

## Требования

- Использованы `switch` с `default` и `if` / `else if` / `else`.
- Баланс не может стать отрицательным от снятия.
- Программа компилируется и запускается командой `java Main.java`.
- Комментарии объясняют только неочевидные места.
