# Практическая работа № 4

## Тема

Условия: `if` / `else if` / `else` и `switch`.

## Цель работы

Научиться строить ветвления и меню выбора, правильно расставлять порядок условий.

## Задание

Магазин электроники «Умный дом» вводит систему лояльности. Напишите программу, которая:

1. Спрашивает сумму покупки за сегодня (`double`) и количество покупок за последний месяц (`int`).
2. Вычисляет скидку по сумме корзины:

| Сумма покупки | Скидка |
| ------------- | ------ |
| от 5000 руб. | 15% |
| от 2000 руб. | 10% |
| от 500 руб. | 5% |
| меньше 500 руб. | 0% |

3. Если за месяц было 4 или больше покупок, к скидке добавляется ещё 3% (используйте `&&` с проверкой суммы >= 500).
4. Вычисляет итог к оплате и бонусные баллы: 1 балл за каждые 100 руб. итоговой суммы (целочисленно, через `(int)`).
5. Выводит всё через `printf`: исходную сумму, размер скидки (в процентах), итог, баллы.

Дополнительно сделайте меню на `switch`: после расчёта спросить «1 — показать чек, 2 — показать только итог», и вывести соответствующее.

## Требования

- Порядок условий: от наибольшей суммы к наименьшей.
- Использованы `if` / `else if` / `else`, `&&`, цепочка `switch` с `default`.
- Скидка и итог считаются в процентах формулой `sum * (100 - discount) / 100`.
- Программа компилируется и запускается командой `java Main.java`.

Пример работы (сумма 3400, покупок 5, выбрано «1»):

```
Сумма покупки: 3400
Покупок за месяц: 5
Скидка: 13%
Итог: 2958.00 руб.
Бонусные баллы: 29
Меню (1 — чек, 2 — итог): 1
--- Чек ---
К оплате: 2958.00 руб.
```
