# Домашнее задание

## Цель

Закрепить циклы `for` и `while` на задаче спортивной подготовки.

## Задание

Программа «Тренировочный план к марафону».

Начните программу с `Locale.setDefault(Locale.US);` — дистанции дробные, вводиться они будут с точкой.

**Часть 1 — план (цикл `while`).** Студент вводит текущую недельную дистанцию (`double`) и начинает готовиться. Каждую следующую неделю дистанция увеличивается на 5% от прошлой (`distance = distance * 1.05`). Цель — 42 км. Программа считает недели и выводит прогресс:

```
Неделя 1: 10.5 км
Неделя 2: 11.02 км
...
```

После достижения цели выводит итоговое число недель.

**Часть 2 — суммарный километраж (цикл `for`).** Отдельно посчитайте, сколько километров набегает атлет за первые 6 недель, если прибавляет по 2 км к прошлой неделе (старт — введённая дистанция). Суммируйте в цикле `for (int week = 1; week <= 6; week++)` и выведите итог.

## Требования

- Часть 1 использует `while`, условие — «пока дистанция меньше 42».
- Часть 2 использует `for`.
- Дистанция выводится с двумя знаками после запятой (`printf` / `%.2f`).
- Программа компилируется и запускается командой `java Main.java`.
- Комментарии объясняют формулы, а не очевидные строки.
