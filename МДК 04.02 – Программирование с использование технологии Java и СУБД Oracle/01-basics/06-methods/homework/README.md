# Домашнее задание

## Цель

Закрепить умение объявлять методы, передавать параметры и возвращать значения из методов.

## Задание

Написать программу для расчёта стоимости товара со скидкой. Пользователь вводит цену товара и размер скидки в процентах. Программа должна рассчитать сумму скидки и итоговую цену, а также вывести результат на экран с помощью метода.

## Требования

- Создать метод `calculateDiscount(double price, double discountPercent)`, который возвращает сумму скидки.
- Создать метод `calculateFinalPrice(double price, double discount)`, который возвращает итоговую цену товара с учётом скидки.
- Создать метод `printResult(double price, double discountPercent, double discountSum, double finalPrice)`, который выводит все расчёты на экран (`void`).
- В методе `main` считать с клавиатуры цену товара и процент скидки.
- Использовать `Locale.setDefault(Locale.US)`.
- Класс `Main`, запуск через `java Main.java`.

## Пример работы программы

```
Введите цену товара: 1000.0
Введите размер скидки в процентах: 15.0
Цена товара: 1000.0 руб.
Скидка: 15.0 %
Сумма скидки: 150.0 руб.
Итого к оплате: 850.0 руб.
```

## Что необходимо предоставить

- Файл `Main.java` с полностью выполненным заданием
- Код должен компилироваться и запускаться без ошибок
