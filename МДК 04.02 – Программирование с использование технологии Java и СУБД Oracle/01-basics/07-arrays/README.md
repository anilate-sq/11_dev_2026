# Массивы

## Цель занятия

Научиться хранить набор однотипных значений в массиве: создавать массив, обращаться к элементам по индексу, обходить циклом и считать сводные показатели.

## Что сегодня изучаем?

- зачем массивы и чем они удобнее набора отдельных переменных;
- создание массива: `new int[n]` и заполнение значениями сразу;
- индексы (нумерация с нуля) и свойство `length`;
- обход массива циклом `for`;
- поиск максимума, минимума и среднего значения;
- двумерные массивы — «таблица» строк и столбцов.

## Основная терминология

| Термин | Определение |
| ------ | ----------- |
| Массив | Упорядоченная коллекция однотипных значений фиксированной длины |
| Индекс | Позиция элемента в массиве, отсчёт начинается с 0 |
| Элемент | Одно значение внутри массива |
| `length` | Количество элементов массива |
| Двумерный массив | Массив массивов; адресуется как `таблица[строка][столбец]` |
| `ArrayIndexOutOfBoundsException` | Ошибка обращения к элементу с несуществующим индексом |

## Теория

Часто нужно хранить много однотипных значений: цены заказа, оценки ученика, продажи за неделю. Заводить отдельную переменную под каждое значение неудобно — их станет десятки, и циклом по ним пройти не выйдет. Массив решает это: один тип данных, фиксированная длина, обращение по номеру — индексу.

Главное свойство массива — длина фиксируется в момент создания. Можно прочитать любой элемент по индексу или записать в него, но добавить «ещё один элемент в конец» нельзя. Длина доступна через `arr.length`.

Индексация начинается с нуля: в массиве из 3 элементов легальные индексы — 0, 1 и 2. Обращение к `arr[3]` (и любому большему номеру) приводит к ошибке `ArrayIndexOutOfBoundsException`.

Массивы почти всегда обходятся циклом `for` с индексом от 0 до `length - 1`. Два массива одинаковой длины можно связать по индексу: `items[i]` и `prices[i]` — товар и его цена. Двумерный массив — это массив одномерных: `sales[i][j]` читается как «строка i, столбец j», удобно для таблиц (дни недели x кассы, предметы x ученики).

## Базовый синтаксис

```java
int[] prices = new int[3];   // три элемента, сейчас все равны 0
prices[0] = 220;
prices[1] = 350;
prices[2] = 180;

int[] ratings = {5, 4, 5};   // массив из трёх значений сразу

System.out.println(prices.length); // 3
System.out.println(prices[0]);     // 220

for (int i = 0; i < prices.length; i++) {
    System.out.println(prices[i]);
}
```

- `int[] prices = new int[3];` — создаётся массив на 3 элемента типа `int`; тип элемента указывается один раз перед именем.
- `prices[0] = 220;` — запись значения по индексу (индексы 0, 1, 2).
- `int[] ratings = {5, 4, 5};` — короткий способ задать массив вместе со значениями.
- `prices.length` — размер массива, всегда актуален.
- Цикл `for` идёт от 0 до `length - 1` включительно — это универсальный способ обойти массив.

Когда индекс внутри цикла не нужен, существует короткая форма обхода: `for (int rating : ratings) { ... }` — «для каждой оценки из массива».

## Практические примеры

### Пример 1. Чек заказа в кафе

```java
public class Main {
    public static void main(String[] args) {
        String[] items = {"Капучино", "Чизкейк", "Круассан"};
        int[] prices = {220, 350, 180};

        System.out.println("=== Ваш заказ ===");
        int total = 0;
        for (int i = 0; i < items.length; i++) {
            System.out.println((i + 1) + ". " + items[i] + " — " + prices[i] + " руб.");
            total = total + prices[i];
        }
        System.out.println("Итого: " + total + " руб.");
    }
}
```

Вывод:

```
=== Ваш заказ ===
1. Капучино — 220 руб.
2. Чизкейк — 350 руб.
3. Круассан — 180 руб.
Итого: 750 руб.
```

Два массива связаны индексом: под номером `i` лежит товар и его цена. Сумма копится в переменной `total` на каждом шаге цикла.

### Пример 2. Оценки ученика

```java
import java.util.Locale;
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Locale.setDefault(Locale.US);

        Scanner scanner = new Scanner(System.in);
        int[] marks = new int[5];

        for (int i = 0; i < marks.length; i++) {
            System.out.print("Оценка " + (i + 1) + ": ");
            marks[i] = scanner.nextInt();
        }

        int sum = 0;
        int max = marks[0];
        int min = marks[0];
        for (int mark : marks) {
            sum = sum + mark;
            if (mark > max) {
                max = mark;
            }
            if (mark < min) {
                min = mark;
            }
        }

        double average = (double) sum / marks.length;
        System.out.println("Средний балл: " + average);
        System.out.println("Максимум: " + max + ", минимум: " + min);
        scanner.close();
    }
}
```

Ввод оценок `5 4 3 5 5`, вывод:

```
Средний балл: 4.4
Максимум: 5, минимум: 3
```

Данные сначала складываются в массив, а уже потом анализируются — так удобнее, чем считать максимум прямо во время ввода, если показатели понадобятся повторно.

### Пример 3. Продажи двух касс за три дня

```java
public class Main {
    public static void main(String[] args) {
        int[][] sales = {
            {12000, 9500, 11200},
            {8700, 10100, 9900}
        };
        String[] cashiers = {"Касса 1", "Касса 2"};

        for (int row = 0; row < sales.length; row++) {
            int total = 0;
            for (int col = 0; col < sales[row].length; col++) {
                total = total + sales[row][col];
            }
            System.out.println(cashiers[row] + ": " + total + " руб.");
        }
    }
}
```

Вывод:

```
Касса 1: 32700 руб.
Касса 2: 28700 руб.
```

`sales.length` — количество строк (касс), `sales[row].length` — количество столбцов (дней) в строке `row`. Внешний цикл перебирает кассы, внутренний — суммирует дни одной кассы.

## Разбор примера

Разберём пример 1 — чек заказа.

- `String[] items = {"Капучино", "Чизкейк", "Круассан"};` — массив строк создаётся вместе со значениями в фигурных скобках; так же создаются и массивы чисел.
- `items[i]` и `prices[i]` — чтение элемента по индексу. Связь «товар — цена» держится только на совпадении индексов: если размеры массивов разные, часть пар просто не сматчится, компилятор этого не проверяет.
- `for (int i = 0; i < items.length; i++)` — условие `i < items.length`, а не `<=`: последний легальный индекс — `length - 1`. Типичная ошибка новичка — цикл до `<= length`, он заканчивается ошибкой `ArrayIndexOutOfBoundsException`.
- `total = total + prices[i]` — знакомый аккумулятор из темы про циклы: массив отдаёт значения по одному, цикл их суммирует.
- В примере 2 стартовые `max` и `min` взяты из первого элемента массива (`marks[0]`), а не из «фантазийного» числа вроде 0 — массив может быть пустым или содержать отрицательные значения, поэтому опираться надо на реальный элемент.

## Итоги занятия

- Массив хранит однотипные значения с фиксированной длиной.
- Элементы адресуются индексами от 0 до `length - 1`.
- Массив почти всегда обходится циклом `for` с индексами от 0 до `length - 1`.
- Два массива одинаковой длины можно связать по индексу (параллельные массивы).
- Двумерный массив адресуется как `таблица[i][j]` и удобен для данных-таблиц.
- Выход за границы массива — ошибка выполнения `ArrayIndexOutOfBoundsException`.
