# Домашнее задание

## Цель

Закрепить одномерные и двумерные массивы на задаче с журналом оценок.

## Задание

Программа «Журнал контрольных работ» собирает оценки двух классных предметов: математика и физика. Учеников в классе — 6.

Начните программу с `Locale.setDefault(Locale.US);` — средние баллы дробные, выводиться они будут через `printf`.

**Часть 1 — один предмет.** Циклом прочитайте 6 оценок по математике в одномерный массив `int[]`. Посчитайте средний балл и количество оценок 4 и 5. Выведите сам массив в строку и оба показателя.

**Часть 2 — два предмета.** Объявите двумерный массив `int[2][6]`: строка 0 — математика, строка 1 — физика. Прочитайте в него оценки по обоим предметам (6 + 6 чисел) и далее циклами посчитайте:

- средний балл по каждому предмету (два значения);
- какой предмет в целом выше по среднему баллу;
- по сколько оценок 4 и 5 у каждого предмета;
- сколько учеников получили хотя бы одну двойку (для каждого предмета отдельно).

Выведите результат в виде сводки:

```
Математика: средний балл 4.17, оценок 4-5: 9, учеников с двойкой: 1
Физика: средний балл 3.83, оценок 4-5: 7, учеников с двойкой: 2
Выше по среднему: математика
```

## Требования

- Часть 1 — одномерный массив и цикл `for`.
- Часть 2 — двумерный массив `int[2][6]`, внешний цикл по предметам, внутренний по ученикам.
- Средний балл — `double`, вывод через `printf` с двумя знаками после запятой.
- Номера и индексы не путаются: ученик под индексом 0 — это первый ученик.
- Комментарии объясняют формулы, а не очевидные строки.
- Программа компилируется и запускается командой `java Main.java`.
