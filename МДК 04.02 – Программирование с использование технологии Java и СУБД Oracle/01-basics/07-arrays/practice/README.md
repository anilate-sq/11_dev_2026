# Практическая работа № 7

## Тема

Массивы: создание, индексы, обход циклом, сводные показатели.

## Цель работы

Научиться заполнять массив с клавиатуры, обходить его циклом `for` и считать по нему сумму, среднее, максимум, минимум и количество подходов по условию.

## Задание

Программа «Анализ продаж кофейни» обрабатывает продажи за несколько дней.

1. Спросите у пользователя, сколько дней анализируем (от 3 до 30) и создайте массив `double[]` нужной длины.
2. Циклом прочитайте продажу за каждый день и сохраните в массив.
3. Пройдите по массиву циклом `for` с индексом и посчитайте:
   - общую сумму продаж;
   - среднюю продажу в день (сумма / число дней);
   - день с максимальной продажей (номер и сумму);
   - день с минимальной продажей (номер и сумму);
   - количество дней, в которых продажа была выше средней.
4. Выведите результат одной аккуратной сводкой.

Начните с заготовки `practice/Main.java`.

## Требования

- Массив создаётся после ввода размера командой `new double[days]`.
- Данные читаются в массив циклом `for` по индексам, анализ — вторым проходом по массиву (или одним проходом, где считается всё нужное).
- Программа начинается с `Locale.setDefault(Locale.US);` — дробные числа вводятся с точкой.
- Номер дня выводится как `maxIndex + 1`, а не как индекс.
- Дробные суммы выводятся с двумя знаками после запятой (`printf` / `%.2f`).
- Комментарии объясняют формулы, а не очевидные строки.
- Программа компилируется и запускается командой `java Main.java`.

Пример работы (дней 5; продажи 12000.5, 9800, 15400.25, 7300, 11250.75):

```
Сколько дней анализируем (3-30): 5
Продажа за день 1: 12000.5
Продажа за день 2: 9800
Продажа за день 3: 15400.25
Продажа за день 4: 7300
Продажа за день 5: 11250.75
=== Итоги ===
Сумма: 55751.50 руб.
Средняя продажа: 11150.30 руб.
Максимум: день 3, 15400.25 руб.
Минимум: день 4, 7300.00 руб.
Дней с продажей выше средней: 3
```
