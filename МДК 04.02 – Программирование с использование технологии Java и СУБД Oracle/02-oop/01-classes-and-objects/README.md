# Классы и объекты

## Цель занятия
Научиться описывать сущность классом и создавать объекты с собственным состоянием.

## Что сегодня изучаем?
- Класс как описание объектов.
- Поля и методы.
- Создание объектов оператором `new` и доступ к членам через точку.

## Основная терминология
| Термин | Определение |
| ------ | ----------- |
| Класс | Описание данных и поведения объектов |
| Объект | Экземпляр класса в памяти |
| Поле | Переменная, хранящая состояние объекта |
| Метод | Действие, определённое в классе |

## Теория
Класс описывает общую структуру сущности, например товара: название, цена и операция показа информации. Объект — конкретный товар с собственными значениями полей.

В Java объект создаётся через `new`. Несколько объектов одного класса имеют одинаковый набор полей, но независимые значения. Метод вызывается у конкретного объекта и может читать или менять его состояние.

## Базовый синтаксис
```java
class Product {
    String name;
    double price;

    void printInfo() {
        System.out.println(name + ": " + price);
    }
}

Product product = new Product();
product.name = "Чай";
product.price = 120.0;
product.printInfo();
```
Поля хранят состояние, метод задаёт поведение; `new Product()` создаёт экземпляр.

## Практические примеры
### Пример 1. Два товара
```java
class Product {
    String name;
    double price;
    void printInfo() { System.out.println(name + " — " + price + " руб."); }
}
```
### Пример 2. Счётчик просмотров
```java
class Article {
    String title;
    int views;
    void view() { views++; }
}
```

## Разбор примера
В `demo/Main.java` два товара создаются независимо. Изменение цены одного не затрагивает другой. Метод `printInfo` использует поля того объекта, у которого вызван.

## Итоги занятия
- Класс задаёт общую форму объектов.
- Поля хранят состояние, методы выполняют действия.
- Каждый вызов `new` создаёт отдельный объект.
