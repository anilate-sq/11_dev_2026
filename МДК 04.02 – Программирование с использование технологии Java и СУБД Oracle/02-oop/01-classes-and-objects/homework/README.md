# Домашнее задание

## Цель
Закрепить создание классов с полями и методами на модели библиотечных книг.

## Задание
Создайте класс `Book` с названием, автором и числом страниц. Создайте несколько книг и выведите информацию о каждой. Добавьте метод, который печатает краткую карточку книги.

## Требования
- Используйте отдельный объект для каждой книги.
- Метод карточки выводит все три характеристики.
- В `main` создайте не менее трёх книг.

## Что необходимо предоставить
- Исходный `Main.java`.
- Ссылку на commit и пример запуска.
