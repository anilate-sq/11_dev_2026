# Практическая работа № X

## Тема

Классы и объекты

## Цель работы

Создавать объекты товаров, хранить состояние в полях и выполнять действия методами.

## Задание

Разработайте каталог товаров для небольшого магазина. Создайте класс `Product` с названием, ценой и остатком на складе. Создайте не менее трёх товаров, выведите карточки и выполните продажу одного товара.

## Требования

Список того, что программа должна уметь.

- Каждый товар — отдельный объект с полями `name`, `price`, `stock`.
- Метод печати показывает все характеристики товара.
- Метод продажи уменьшает остаток на указанное количество.
- Демонстрация показывает состояние до и после продажи.

## Формат результата

Что студент должен предоставить преподавателю.

- Исходный `Main.java` и ссылка на commit.
- Кратко опишите созданные классы и методы.
