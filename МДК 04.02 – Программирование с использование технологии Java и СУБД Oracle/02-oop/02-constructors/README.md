# Конструкторы

## Цель занятия
Научиться создавать объекты сразу с корректно заданными начальными значениями.

## Что сегодня изучаем?
- Назначение и синтаксис конструктора.
- Параметры конструктора и `this`.
- Перегрузка конструкторов.

## Основная терминология
| Термин | Определение |
| ------ | ----------- |
| Конструктор | Специальный код инициализации нового объекта |
| Параметр | Входное значение метода или конструктора |
| `this` | Ссылка на текущий объект |
| Перегрузка | Несколько методов/конструкторов с разными параметрами |

## Теория
Конструктор вызывается при создании объекта и имеет то же имя, что класс, но не имеет типа возвращаемого значения. Параметры позволяют передать начальные данные и избежать состояния с незаданными полями.

`this.name = name` присваивает полю текущего объекта значение параметра. Если объявить собственный конструктор, компилятор уже не добавляет конструктор без параметров автоматически.

## Базовый синтаксис
```java
class Product {
    String name;
    double price;
    Product(String name, double price) {
        this.name = name;
        this.price = price;
    }
}
Product tea = new Product("Чай", 120.0);
```
После `new` Java выбирает конструктор, соответствующий переданным аргументам.

## Практические примеры
### Пример 1. Создание заказа
```java
class Order {
    int number;
    String customer;
    Order(int number, String customer) { this.number = number; this.customer = customer; }
}
```
### Пример 2. Несколько вариантов создания
```java
class Label {
    String text;
    Label() { this("Без названия"); }
    Label(String text) { this.text = text; }
}
```

## Разбор примера
Демонстрация создаёт заказ с номером и именем клиента, затем печатает поля. Перегруженный конструктор метки делегирует работу основному через `this(...)`; такой вызов должен быть первой строкой конструктора.

## Итоги занятия
- Конструктор выполняется при `new`.
- `this` помогает отличать поле от параметра.
- Перегрузка предоставляет несколько способов инициализации.
