# Домашнее задание

## Цель
Закрепить инициализацию объектов с помощью конструкторов.

## Задание
Создайте класс `UserProfile` с именем пользователя и электронной почтой. Инициализируйте оба значения конструктором; добавьте перегруженный вариант, принимающий только имя и задающий адрес-заглушку.

## Требования
- Используйте `this` для присваивания полей.
- Создайте минимум два профиля разными конструкторами.
- Добавьте метод вывода профиля.

## Что необходимо предоставить
- Исходный `Main.java`.
- Ссылку на commit и краткое описание конструкторов.
