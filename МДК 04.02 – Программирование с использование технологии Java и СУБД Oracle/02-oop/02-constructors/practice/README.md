# Практическая работа № X

## Тема

Конструкторы

## Цель работы

Создавать объекты заказов с данными, переданными в конструктор.

## Задание

Создайте класс `Order` для заказа интернет-магазина. При создании заказа передавайте номер, имя покупателя и стоимость. Добавьте перегруженный конструктор для заказа без стоимости, который задаёт стоимость 0, и метод печати сводки.

## Требования

Список того, что программа должна уметь.

- Используйте `this` для присваивания параметров полям.
- Создайте минимум три заказа обоими конструкторами.
- Выведите сводку каждого заказа.

## Формат результата

Что студент должен предоставить преподавателю.

- Исходный `Main.java` и ссылка на commit.
- Краткое описание конструкторов и тестовых объектов.
