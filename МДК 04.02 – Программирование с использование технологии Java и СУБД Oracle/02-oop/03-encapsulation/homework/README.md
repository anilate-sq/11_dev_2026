# Домашнее задание

## Цель
Закрепить инкапсуляцию и проверку состояния объекта.

## Задание
Реализуйте класс `Thermostat` с закрытой температурой. Добавьте метод установки температуры, принимающий только значения от 10 до 30 градусов включительно, и метод отображения текущего значения.

## Требования
- Поле температуры имеет модификатор `private`.
- Недопустимое значение не меняет состояние.
- Покажите успешное и отклонённое изменение.

## Что необходимо предоставить
- Исходный `Main.java`.
- Ссылку на commit и примеры проверенных значений.
