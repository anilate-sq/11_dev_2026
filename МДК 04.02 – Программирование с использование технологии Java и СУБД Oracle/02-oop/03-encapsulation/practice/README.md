# Практическая работа № X

## Тема

Инкапсуляция

## Цель работы

Защищать баланс банковского счёта и изменять его только проверяемыми операциями.

## Задание

Разработайте класс `BankAccount`. Клиент должен иметь возможность пополнять счёт и снимать деньги, но не менять баланс напрямую. После каждой операции выведите результат и текущий баланс.

## Требования

Список того, что программа должна уметь.

- Поля владельца и баланса закрыты (`private`).
- Пополнение и снятие отклоняют неположительные суммы; снятие также отклоняется при недостаточном балансе.
- Выведите баланс до и после нескольких успешных и отклонённых операций.

## Формат результата

Что студент должен предоставить преподавателю.

- Исходный `Main.java` и ссылка на commit.
- Перечень проверенных сценариев.
