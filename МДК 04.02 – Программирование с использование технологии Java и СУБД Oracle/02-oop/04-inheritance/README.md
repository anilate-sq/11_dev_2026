# Наследование

## Цель занятия
Научиться выделять общие свойства связанных типов в базовый класс и расширять его.

## Что сегодня изучаем?
- Наследование через `extends`.
- `super` и вызов конструктора родителя.
- Переопределение методов и `@Override`.

## Основная терминология
| Термин | Определение |
| ------ | ----------- |
| Базовый класс | Класс, общие свойства которого наследуются |
| Подкласс | Класс, расширяющий другой класс |
| Переопределение | Новая реализация унаследованного метода |
| `super` | Обращение к реализации/конструктору родителя |

## Теория
Наследование выражает отношение «является»: например, `CardPayment` является способом оплаты. Подкласс получает доступные ему поля и методы базового класса и может добавить собственные.

Конструктор базового класса вызывается через `super(...)`; такой вызов ставится первой строкой. Метод можно переопределить, сохраняя сигнатуру и добавляя `@Override`. Наследование стоит применять для действительно общей модели, а не только ради повторного использования кода.

## Базовый синтаксис
```java
class Payment {
    protected double amount;
    Payment(double amount) { this.amount = amount; }
    void pay() { System.out.println("Оплата: " + amount); }
}
class CardPayment extends Payment {
    CardPayment(double amount) { super(amount); }
    @Override void pay() { System.out.println("Оплата картой: " + amount); }
}
```
`extends` задаёт родителя, `super` инициализирует его часть объекта.

## Практические примеры
### Пример 1. Сотрудники
Базовый `Employee` хранит имя, а `Manager` добавляет название отдела.
### Пример 2. Способы доставки
`Delivery` задаёт общий заказ, а `CourierDelivery` добавляет адрес и переопределяет описание.

## Разбор примера
В демонстрации подклассы вызывают конструктор `Payment`, а переопределённый метод каждого типа оплаты показывает его специфичное поведение.

## Итоги занятия
- Подкласс расширяет базовый класс с помощью `extends`.
- `super(...)` вызывает конструктор родителя.
- `@Override` отмечает переопределённый метод.
