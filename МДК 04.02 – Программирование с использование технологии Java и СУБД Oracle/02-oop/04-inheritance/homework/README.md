# Домашнее задание

## Цель
Закрепить наследование на модели сотрудников организации.

## Задание
Создайте базовый класс `Employee` с именем и методом вывода сведений. Добавьте подкласс `Developer` с языком программирования и подкласс `Manager` с размером команды. Расширьте вывод в каждом подклассе.

## Требования
- Подклассы наследуются от `Employee`.
- Конструкторы подклассов вызывают `super(...)`.
- Переопределённый метод отмечен `@Override`.
- Создайте и выведите сведения о сотрудниках обоих типов.

## Что необходимо предоставить
- Исходный `Main.java`.
- Ссылку на commit и описание общей/специфичной информации.
