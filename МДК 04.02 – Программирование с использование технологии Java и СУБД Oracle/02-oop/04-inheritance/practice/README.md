# Практическая работа № X

## Тема

Наследование

## Цель работы

Выделять общее состояние доставки в базовый класс и расширять его подклассами.

## Задание

Создайте базовый класс `Delivery` с номером заказа и методом описания. Реализуйте `CourierDelivery` с адресом и `PickupDelivery` с пунктом выдачи. Каждый подкласс выводит собственные детали.

## Требования

Список того, что программа должна уметь.

- Подклассы используют `extends` и вызывают `super(...)`.
- Переопределите общий метод описания с `@Override`.
- Создайте объекты обоих типов и выведите информацию.

## Формат результата

Что студент должен предоставить преподавателю.

- Исходный `Main.java` и ссылка на commit.
- Краткое описание общей и специфичной частей классов.
