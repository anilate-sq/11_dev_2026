# Полиморфизм

## Цель занятия
Научиться обрабатывать объекты разных подклассов единообразно через общий базовый тип.

## Что сегодня изучаем?
- Ссылка базового типа на объект подкласса.
- Динамический выбор переопределённого метода.
- Полиморфная обработка массива объектов.

## Основная терминология
| Термин | Определение |
| ------ | ----------- |
| Полиморфизм | Единый вызов приводит к поведению конкретного типа объекта |
| Базовый тип | Общий родительский тип переменной |
| Динамический выбор | Выбор реализации метода во время выполнения |
| Приведение типа | Явное преобразование ссылки к другому типу |

## Теория
Переменная базового типа может ссылаться на объект любого подкласса. При вызове переопределённого метода Java выбирает реализацию по фактическому типу объекта во время выполнения.

Это позволяет написать обработчик один раз для коллекции однотипных по контракту объектов. Полиморфизм не означает, что становятся доступны любые поля подкласса: доступны члены объявленного типа ссылки.

## Базовый синтаксис
```java
Payment[] payments = { new CardPayment(1200), new CashPayment(500) };
for (Payment payment : payments) {
    payment.pay();
}
```
Цикл не проверяет конкретный подкласс: вызов `pay()` выбирает нужную реализацию.

## Практические примеры
### Пример 1. Виды доставки
Один цикл вызывает `calculateCost()` у курьерской и почтовой доставки.
### Пример 2. Отчёты сотрудников
Разные подклассы формируют собственное описание через общий метод.

## Разбор примера
В демо массив `Payment[]` хранит разные способы оплаты. Несмотря на общий тип ссылок, вызывается переопределённый метод каждого объекта.

## Итоги занятия
- Ссылка родителя может содержать объект подкласса.
- Переопределённая реализация выбирается по типу объекта.
- Общий тип упрощает обработку набора разных объектов.
