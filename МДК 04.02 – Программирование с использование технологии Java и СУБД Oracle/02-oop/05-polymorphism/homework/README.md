# Домашнее задание

## Цель
Закрепить полиморфную обработку объектов через общий базовый тип.

## Задание
Создайте базовый класс `Notification` и подклассы `EmailNotification` и `SmsNotification`. Переопределите метод отправки и обработайте массив разных уведомлений единым циклом.

## Требования
- Каждый подкласс задаёт собственную реализацию отправки.
- В массиве базового типа есть не менее двух видов уведомлений.
- Для каждого объекта вызывается общий метод без проверки типа.

## Что необходимо предоставить
- Исходный `Main.java`.
- Ссылку на commit и пример вывода программы.
