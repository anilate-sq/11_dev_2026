# Практическая работа № X

## Тема

Полиморфизм

## Цель работы

Обрабатывать разные виды доставки через ссылку базового типа и переопределённое поведение.

## Задание

Расширьте модель доставки подклассами курьерской и почтовой доставки. Реализуйте расчёт стоимости и примените единый цикл к массиву объектов базового типа.

## Требования

Список того, что программа должна уметь.

- Оба подкласса переопределяют расчёт стоимости.
- Массив имеет тип `Delivery[]` и содержит объекты разных подклассов.
- Для каждого объекта выведите номер и рассчитанную стоимость.

## Формат результата

Что студент должен предоставить преподавателю.

- Исходный `Main.java` и ссылка на commit.
- Пример вывода и пояснение выбора реализации метода.
