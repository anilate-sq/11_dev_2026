# Домашнее задание

## Цель
Закрепить проектирование интерфейса и нескольких его реализаций.

## Задание
Объявите интерфейс `Exportable` с методом экспорта текстового представления. Реализуйте его классами `Invoice` и `ProductReport`; обработайте объекты через массив интерфейсного типа.

## Требования
- Классы реализуют интерфейс через `implements`.
- Метод интерфейса реализован как `public`.
- Каждая реализация возвращает собственный осмысленный текст.
- Общий код вызывает метод через тип `Exportable`.

## Что необходимо предоставить
- Исходный `Main.java`.
- Ссылку на commit и краткое описание контракта.
