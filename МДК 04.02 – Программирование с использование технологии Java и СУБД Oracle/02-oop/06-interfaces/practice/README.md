# Практическая работа № X

## Тема

Интерфейсы

## Цель работы

Определять общий интерфейс для классов, выполняющих одинаковую операцию разными способами.

## Задание

Создайте интерфейс `Printable` с методом `print()`. Реализуйте его классами `Invoice` и `ShippingLabel`, затем обработайте объекты обоих типов единым циклом.

## Требования

Список того, что программа должна уметь.

- Оба класса реализуют `Printable` и предоставляют публичную реализацию метода.
- Используйте массив `Printable[]`.
- Вывод каждого типа содержит его собственные данные.

## Формат результата

Что студент должен предоставить преподавателю.

- Исходный `Main.java` и ссылка на commit.
- Краткое описание контракта и его реализаций.
