Научиться моделировать реальные сущности классами и объектами, защищать их состояние и строить взаимодействующие типы.

## Результат обучения

После завершения блока студент умеет описывать классы с полями и методами, создавать и инициализировать объекты, защищать состояние через инкапсуляцию, применять наследование и полиморфизм, задавать общий контракт интерфейсом и проектировать простую предметную модель.
