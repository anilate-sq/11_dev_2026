# Массивы

## Цель занятия

Научиться хранить фиксированный набор однотипных значений, получать доступ к элементам по индексу и обрабатывать данные циклом. После занятия студент сможет посчитать сумму и среднее значение, найти элемент и определить границы массива.

## Что сегодня изучаем?

Список основных вопросов занятия.

- объявление, создание и заполнение массива;
- индексы, длина массива и безопасный доступ;
- обход массива циклом `for` и `for-each`, поиск и агрегирование.

## Основная терминология

| Термин | Определение |
| ------ | ----------- |
| Массив | Структура фиксированной длины для хранения значений одного типа. |
| Индекс | Номер элемента; в Java отсчёт начинается с нуля. |
| `length` | Свойство массива, содержащее количество его элементов. |
| `for-each` | Цикл для последовательного чтения элементов массива. |

## Теория

Массив нужен, когда программе требуется хранить несколько значений одного типа под одним именем. Например, дневные продажи можно представить как `double[] sales`, а оценки — как `int[] grades`. Каждый элемент расположен в последовательной позиции, доступной по индексу.

Размер массива задаётся при создании и не меняется. Если заранее неизвестно, сколько элементов понадобится, позже будем использовать `ArrayList`. Индексы начинаются с нуля: в массиве длины 5 допустимы индексы от 0 до 4. Обращение к индексу вне этого диапазона приводит к `ArrayIndexOutOfBoundsException`.

Массив можно заполнить значениями сразу или создать нужного размера. Для обработки с индексом используют обычный `for`; когда нужен только каждый элемент по очереди — более компактный `for-each`. Переменная `length` не является методом: пишется `values.length`, без скобок.

## Базовый синтаксис

```java
int[] quantities = {4, 7, 2};
int[] scores = new int[5];

for (int i = 0; i < quantities.length; i++) {
    System.out.println("Элемент " + i + ": " + quantities[i]);
}

for (int score : scores) {
    System.out.println(score);
}
```

Фигурные скобки задают значения при объявлении. `new int[5]` создаёт массив из пяти элементов, заполненных значением по умолчанию (`0`). Условие `i < quantities.length` не позволяет выйти за последний индекс. В `for-each` переменная `score` по очереди получает значения элементов; изменить через неё элемент массива нельзя.

## Практические примеры

### Пример 1. Итоги продаж за неделю

```java
import java.util.Locale;

public class Main {
    public static void main(String[] args) {
        Locale.setDefault(Locale.US);
        double[] sales = {1250.50, 980.00, 1430.75, 1100.00, 875.25};
        double total = 0;

        for (double sale : sales) {
            total += sale;
        }

        double average = total / sales.length;
        System.out.printf("Сумма продаж: %.2f%n", total);
        System.out.printf("Средняя продажа: %.2f%n", average);
    }
}
```

### Пример 2. Поиск минимальной температуры

```java
public class Main {
    public static void main(String[] args) {
        int[] temperatures = {18, 21, 16, 19, 23, 15};
        int minimum = temperatures[0];

        for (int i = 1; i < temperatures.length; i++) {
            if (temperatures[i] < minimum) {
                minimum = temperatures[i];
            }
        }

        System.out.println("Минимальная температура: " + minimum);
    }
}
```

## Разбор примера

В первом примере `for-each` суммирует все продажи. Деление на `sales.length` даёт среднее арифметическое; длина берётся из самого массива, поэтому при изменении набора не нужно обновлять число вручную. Для денежных расчётов в реальном приложении обычно используют `BigDecimal`, но здесь `double` помогает сосредоточиться на массиве.

Во втором примере минимумом временно считается первый элемент. Затем программа проверяет оставшиеся элементы и заменяет минимум при обнаружении меньшего значения. Такой подход работает и с отрицательными числами — в отличие от произвольного начального значения вроде нуля. Перед чтением `temperatures[0]` массив должен быть непустым.

## Итоги занятия

- размер массива фиксирован, а допустимые индексы лежат от `0` до `length - 1`;
- `for` подходит, когда нужен индекс; `for-each` — когда нужны только значения;
- проход по массиву позволяет искать элементы, считать сумму, среднее, минимум и максимум.
