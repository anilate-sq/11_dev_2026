# Домашнее задание: статистика успеваемости

## Цель

Закрепить создание массива, обход элементов и вычисление статистики.

## Задание

Храни оценки группы в массиве `int[]`. Выведи все оценки, найди средний балл, максимальную и минимальную оценку, а также посчитай, сколько студентов получили оценку не ниже 4. Проверь работу на массиве минимум из шести значений.

## Требования

- Не используй готовые функции для поиска минимума и максимума.
- Среднее вычисляй через сумму и длину массива.
- Для поиска минимума и максимума используй элементы массива, а не произвольный стартовый ноль.

## Что необходимо предоставить

- `Main.java`;
- пример результата запуска.
