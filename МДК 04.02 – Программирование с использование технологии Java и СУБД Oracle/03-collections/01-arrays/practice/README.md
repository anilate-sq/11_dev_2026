# Практическая работа № 1

## Тема

Массивы

## Цель работы

Обрабатывать массив показателей магазина и вычислять сводную статистику.

## Задание

В `Main.java` создай массив из пяти значений продаж за рабочую неделю. Выведи продажи по дням, общую сумму, среднее значение, максимальную и минимальную продажу. Дополнительно найди номер дня с максимальной продажей.

## Требования

Список того, что программа должна уметь.

- Используй `for` или `for-each` для обхода массива.
- Не храни длину массива отдельной константой: используй `length`.
- Для максимума и минимума начни с первого элемента массива.

## Формат результата

Что студент должен предоставить преподавателю.

- исходный код `Main.java`;
- пример запуска и краткое описание вычислений.
