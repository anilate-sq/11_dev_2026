# ArrayList

## Цель занятия

Научиться хранить список, размер которого меняется во время работы программы. Студент сможет добавлять, получать, заменять и удалять элементы, обходить список и правильно работать с его размером.

## Что сегодня изучаем?

Список основных вопросов занятия.

- отличие массива фиксированной длины от `ArrayList`;
- операции `add`, `get`, `set`, `remove`, `size`;
- обход списка и использование обобщённого типа, например `ArrayList<String>`.

## Основная терминология

| Термин | Определение |
| ------ | ----------- |
| Коллекция | Объект для хранения и обработки группы значений. |
| `ArrayList<E>` | Список с изменяемым размером; `E` обозначает тип элементов. |
| `size()` | Метод, возвращающий текущее число элементов списка. |
| Обобщённый тип | Указание типа элементов в угловых скобках, например `<String>`. |

## Теория

Массив удобен для фиксированного набора, но его размер нельзя увеличить. `ArrayList` решает задачу динамического списка: он может расти при добавлении элементов и уменьшаться при удалении. Чтобы использовать класс, импортируйте `java.util.ArrayList`.

Тип элементов указывается в угловых скобках: `ArrayList<String>` хранит строки, `ArrayList<Integer>` — целые числа. Коллекции хранят объекты, поэтому для чисел используются классы-обёртки (`Integer`, `Double`), а не примитивные типы `int` и `double`. Java автоматически преобразует значения между `int` и `Integer` в большинстве обычных операций.

Метод `add` добавляет элемент в конец или по указанному индексу, `get` читает, `set` заменяет, `remove` удаляет. `size()` сообщает текущую длину. Удаление по индексу сдвигает следующие элементы влево. Не смешивайте размер списка и последний индекс: последний индекс равен `size() - 1`.

## Базовый синтаксис

```java
import java.util.ArrayList;

ArrayList<String> tasks = new ArrayList<>();
tasks.add("Подготовить отчёт");
tasks.add("Отправить письмо");
String firstTask = tasks.get(0);
tasks.set(0, "Подготовить итоговый отчёт");
tasks.remove(1);
System.out.println("Задач: " + tasks.size());
```

`<>` справа позволяет Java вывести тип из объявления (diamond operator). `add` без индекса добавляет в конец, а остальные методы принимают индекс с нуля. `size()` — метод и поэтому вызывается со скобками.

## Практические примеры

### Пример 1. Список покупок

```java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<String> shoppingList = new ArrayList<>();
        shoppingList.add("Хлеб");
        shoppingList.add("Молоко");
        shoppingList.add("Яблоки");

        for (int i = 0; i < shoppingList.size(); i++) {
            System.out.println((i + 1) + ". " + shoppingList.get(i));
        }
    }
}
```

### Пример 2. Изменение списка заказов

```java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<String> orders = new ArrayList<>();
        orders.add("Заказ #104");
        orders.add("Заказ #105");
        orders.add("Заказ #106");

        orders.set(1, "Заказ #105 — оплачен");
        orders.remove(0);

        for (String order : orders) {
            System.out.println(order);
        }
    }
}
```

## Разбор примера

В списке покупок цикл использует индекс, чтобы вывести порядковый номер. Для обхода без нумерации короче подошёл бы `for-each`. Во втором примере сначала изменяется элемент с индексом 1, а затем удаляется первый заказ; список автоматически уменьшает размер.

Перед `get(index)`, `set(index, value)` и `remove(index)` проверьте допустимость индекса. Ошибка `IndexOutOfBoundsException` часто возникает из-за цикла с условием `i <= list.size()` вместо `i < list.size()`. Удаление элементов внутри индексного цикла требует аккуратности: после удаления элементы сдвигаются.

## Итоги занятия

- `ArrayList` хранит элементы одного объявленного типа и меняет размер динамически;
- индексы начинаются с нуля, число элементов возвращает `size()`;
- основные операции: `add`, `get`, `set`, `remove`.
