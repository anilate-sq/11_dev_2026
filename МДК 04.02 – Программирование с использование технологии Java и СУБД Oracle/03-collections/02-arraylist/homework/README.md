# Домашнее задание: список книг

## Цель

Закрепить операции добавления, замены, удаления и обхода `ArrayList`.

## Задание

Создай список названий книг для небольшой библиотеки. Добавь несколько книг, исправь название одной книги, удали выданную книгу и выведи итоговый список с номерами и количеством записей.

## Требования

- Используй `ArrayList<String>`.
- Прежде чем удалить или заменить запись по индексу, убедись, что индекс допустим.
- Не обращайся к последнему элементу через индекс, равный `size()`.

## Что необходимо предоставить

- `Main.java`;
- краткое описание операций со списком.
