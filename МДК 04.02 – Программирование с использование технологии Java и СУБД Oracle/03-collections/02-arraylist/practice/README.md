# Практическая работа № 2

## Тема

ArrayList

## Цель работы

Создавать и редактировать динамический список задач.

## Задание

Реализуй список дел на день. Начни с нескольких задач, добавь новую, замени одну задачу на более точную формулировку, удали выполненную. Выведи итоговый список с порядковыми номерами и количество оставшихся задач.

## Требования

Список того, что программа должна уметь.

- Используй `ArrayList<String>`.
- Для изменения списка примени `add`, `set` и `remove`.
- При выводе используй актуальное значение `size()`.

## Формат результата

Что студент должен предоставить преподавателю.

- исходный код `Main.java`;
- пример запуска и описание выполненных операций.
