# Set и HashSet

## Цель занятия

Понять, когда нужны уникальные значения, и использовать `Set`/`HashSet` для добавления, поиска и удаления без дубликатов. Студент сможет, например, получить список уникальных адресов электронной почты.

## Что сегодня изучаем?

Список основных вопросов занятия.

- назначение множества и отличие от списка;
- операции `add`, `contains`, `remove`, `size`;
- уникальность элементов и отсутствие гарантированного порядка в `HashSet`.

## Основная терминология

| Термин | Определение |
| ------ | ----------- |
| `Set<E>` | Интерфейс коллекции, содержащей уникальные элементы. |
| `HashSet<E>` | Реализация `Set`, использующая хеширование для поиска и хранения. |
| Дубликат | Значение, равное уже присутствующему элементу. |
| Хеширование | Способ быстро организовать поиск объекта по его хеш-коду. |

## Теория

Список сохраняет последовательность и допускает одинаковые значения. Множество (`Set`) отвечает на другой вопрос: есть ли такое значение и как хранить только уникальные элементы. Поэтому оно подходит для набора тегов, зарегистрированных email-адресов или уже обработанных идентификаторов.

Наиболее часто применяется `HashSet`. При добавлении существующего значения второй экземпляр не появляется, а `add` возвращает `false`; для нового значения возвращается `true`. Проверка `contains` и удаление `remove` полезны, когда порядок элементов не важен.

`HashSet` не обещает порядок обхода. Не следует полагаться на то, что значения будут выводиться в том же порядке, в котором добавлялись. Для собственных объектов корректное определение равенства требует согласованной реализации `equals` и `hashCode`; это изучается вместе с классами и объектами.

## Базовый синтаксис

```java
import java.util.HashSet;
import java.util.Set;

Set<String> tags = new HashSet<>();
tags.add("java");
tags.add("учёба");
tags.add("java");

System.out.println(tags.size()); // 2
System.out.println(tags.contains("java"));
```

Переменная объявлена через интерфейс `Set`, а создана реализация `HashSet`. Повторное добавление не увеличивает размер множества. В реальном файле нужны импорты `java.util.Set` и `java.util.HashSet`.

## Практические примеры

### Пример 1. Уникальные категории

```java
import java.util.HashSet;
import java.util.Set;

public class Main {
    public static void main(String[] args) {
        Set<String> categories = new HashSet<>();
        categories.add("Книги");
        categories.add("Техника");
        categories.add("Книги");

        System.out.println("Уникальных категорий: " + categories.size());
        for (String category : categories) {
            System.out.println(category);
        }
    }
}
```

### Пример 2. Проверка уже зарегистрированного email

```java
import java.util.HashSet;
import java.util.Set;

public class Main {
    public static void main(String[] args) {
        Set<String> registeredEmails = new HashSet<>();
        registeredEmails.add("alex@example.com");
        registeredEmails.add("maria@example.com");

        String newEmail = "alex@example.com";
        if (registeredEmails.add(newEmail)) {
            System.out.println("Адрес зарегистрирован");
        } else {
            System.out.println("Этот адрес уже используется");
        }
    }
}
```

## Разбор примера

В первом примере повторная категория не создаёт второй элемент. Вывод может менять порядок, поскольку `HashSet` его не гарантирует. Во втором примере возвращаемое значение `add` используется сразу как результат проверки уникальности — отдельный вызов `contains` не нужен.

Множество полезно там, где дубликат должен быть исключён по смыслу задачи. Если же важно сохранить порядок добавления или обращаться к элементам по номеру, лучше выбрать список. При сравнении строк учитывается регистр: `User@example.com` и `user@example.com` для `String` различаются; нормализацию данных при необходимости выполняют отдельно.

## Итоги занятия

- `Set` хранит уникальные значения;
- `HashSet` обеспечивает удобные операции добавления, проверки и удаления, но не гарантирует порядок;
- `add` сообщает, было ли значение новым.
