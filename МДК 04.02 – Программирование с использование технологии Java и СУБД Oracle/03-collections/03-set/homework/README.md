# Домашнее задание: уникальные слова

## Цель

Закрепить хранение уникальных значений в множестве.

## Задание

Дан массив слов, в котором некоторые слова повторяются. Добавь их в `HashSet`, выведи число уникальных слов и проверь наличие выбранного слова. Объясни в комментарии, почему количество элементов множества меньше либо равно длине исходного массива.

## Требования

- Создай `Set<String>` на основе `HashSet`.
- Проверь наличие элемента через `contains`.
- Не рассчитывай на фиксированный порядок вывода множества.

## Что необходимо предоставить

- `Main.java`;
- пример запуска.
