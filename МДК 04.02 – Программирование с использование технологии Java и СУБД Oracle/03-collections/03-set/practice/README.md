# Практическая работа № 3

## Тема

Set и HashSet

## Цель работы

Убирать дублирующиеся значения и проверять уникальность данных.

## Задание

Создай набор участников, записавшихся на мероприятие. Добавь несколько адресов электронной почты, включая повторяющиеся. Выведи число уникальных участников и проверь, зарегистрирован ли заданный адрес.

## Требования

Список того, что программа должна уметь.

- Используй интерфейс `Set` и реализацию `HashSet`.
- Покажи результат добавления адреса, который уже встречался.
- Не рассчитывай на порядок вывода элементов множества.

## Формат результата

Что студент должен предоставить преподавателю.

- исходный код `Main.java`;
- пример запуска и краткое объяснение уникальности элементов.
