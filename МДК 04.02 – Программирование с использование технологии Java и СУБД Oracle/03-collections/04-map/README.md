# Map и HashMap

## Цель занятия

Научиться хранить данные парами «ключ — значение», быстро получать значение по ключу и обновлять записи. Студент сможет создать простой каталог товаров или справочник пользователей.

## Что сегодня изучаем?

Список основных вопросов занятия.

- назначение интерфейса `Map` и класса `HashMap`;
- операции `put`, `get`, `getOrDefault`, `containsKey`, `remove`;
- обход пар ключ-значение и уникальность ключей.

## Основная терминология

| Термин | Определение |
| ------ | ----------- |
| `Map<K, V>` | Коллекция пар, где ключ `K` связан со значением `V`. |
| Ключ | Уникальный идентификатор, по которому находят значение. |
| `HashMap<K, V>` | Реализация `Map` на основе хеширования. |
| `entrySet()` | Набор пар карты для удобного обхода. |

## Теория

`Map` нужна, когда элемент ищут не по позиции, а по осмысленному ключу: номер заказа → заказ, логин → профиль, название товара → цена. Типы ключа и значения задаются отдельно, например `Map<String, Integer>`.

Метод `put` добавляет новую пару или заменяет значение по уже существующему ключу. Поэтому ключи уникальны, а значения могут повторяться. `get` возвращает значение по ключу или `null`, если ключ отсутствует; `containsKey` позволяет проверить наличие ключа, а `getOrDefault` — задать запасное значение.

`HashMap` не обещает порядок обхода. Чтобы обработать все пары, удобно перебирать `entrySet()` и у каждой записи вызывать `getKey()` и `getValue()`. Карта не является списком: у неё нет надёжного доступа по позиции.

## Базовый синтаксис

```java
import java.util.HashMap;
import java.util.Map;

Map<String, Integer> stock = new HashMap<>();
stock.put("Кофе", 12);
stock.put("Чай", 8);
int coffeeCount = stock.getOrDefault("Кофе", 0);

for (Map.Entry<String, Integer> item : stock.entrySet()) {
    System.out.println(item.getKey() + ": " + item.getValue());
}
```

`K` обозначает тип ключа, `V` — тип значения. `put` связывает название с количеством. `entrySet()` даёт пары для обхода; порядок печати может отличаться.

## Практические примеры

### Пример 1. Остатки товаров

```java
import java.util.HashMap;
import java.util.Map;

public class Main {
    public static void main(String[] args) {
        Map<String, Integer> stock = new HashMap<>();
        stock.put("Блокнот", 24);
        stock.put("Ручка", 50);
        stock.put("Папка", 12);

        String product = "Ручка";
        System.out.println(product + ": " + stock.getOrDefault(product, 0) + " шт.");
    }
}
```

### Пример 2. Подсчёт количества обращений

```java
import java.util.HashMap;
import java.util.Map;

public class Main {
    public static void main(String[] args) {
        String[] pages = {"/home", "/catalog", "/home", "/about", "/home"};
        Map<String, Integer> visits = new HashMap<>();

        for (String page : pages) {
            int currentCount = visits.getOrDefault(page, 0);
            visits.put(page, currentCount + 1);
        }

        for (Map.Entry<String, Integer> entry : visits.entrySet()) {
            System.out.println(entry.getKey() + " — " + entry.getValue());
        }
    }
}
```

## Разбор примера

В каталоге товары индексируются по названию, а `getOrDefault` позволяет безопасно показать ноль для отсутствующего товара. В подсчёте посещений карта накапливает частоту: сначала читаем текущее значение (или 0), затем записываем увеличенное на единицу.

Распространённая ошибка — считать, что повторный `put` добавит вторую запись с тем же ключом: он заменяет значение. Также `get` может вернуть `null`, поэтому для счётчиков удобнее `getOrDefault`. Если порядок важен, выбирают другую реализацию карты; обычный `HashMap` его не гарантирует.

## Итоги занятия

- `Map` хранит пары «ключ — значение»;
- ключи уникальны, значение по ключу можно обновить;
- `entrySet()` позволяет обойти все пары карты.
