# Домашнее задание: телефонный справочник

## Цель

Закрепить хранение и поиск пар «ключ — значение» в `Map`.

## Задание

Создай телефонный справочник, где ключ — имя контакта, значение — номер телефона. Добавь несколько записей, обнови номер одного контакта, найди номер по имени и выведи все пары справочника.

## Требования

- Используй `Map<String, String>`.
- Обработай ситуацию, когда искомого имени нет.
- Для вывода всех записей используй `entrySet()`.

## Что необходимо предоставить

- `Main.java`;
- пример запуска с найденной записью и отсутствующим контактом.
