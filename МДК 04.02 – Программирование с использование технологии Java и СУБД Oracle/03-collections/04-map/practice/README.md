# Практическая работа № 4

## Тема

Map и HashMap

## Цель работы

Создавать каталог «товар — остаток», обновлять остатки и находить данные по ключу.

## Задание

Создай учёт остатков товаров в магазине. Заполни карту названиями товаров и количеством, измени остаток одного товара, найди остаток по введённому в коде названию и выведи весь каталог.

## Требования

Список того, что программа должна уметь.

- Используй `Map<String, Integer>`.
- Для отсутствующего товара выводи понятное сообщение или значение по умолчанию.
- Перебери каталог через `entrySet()`.

## Формат результата

Что студент должен предоставить преподавателю.

- исходный код `Main.java`;
- пример запуска и описание того, как устроен ключ и значение.
