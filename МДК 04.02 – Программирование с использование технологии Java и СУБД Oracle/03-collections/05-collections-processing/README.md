# Обработка коллекций

## Цель занятия

Научиться применять циклы и методы `Collection` для фильтрации, поиска, подсчёта и преобразования данных. Студент сможет обработать список заказов и получить нужные итоги без Stream API, который изучается позже.

## Что сегодня изучаем?

Список основных вопросов занятия.

- обход `List` и `Set` циклом `for-each`;
- поиск и подсчёт по условию, накопление результата;
- безопасное удаление элементов и сортировка списка.

## Основная терминология

| Термин | Определение |
| ------ | ----------- |
| Обработка коллекции | Последовательный анализ или изменение элементов набора. |
| Фильтрация | Отбор элементов, удовлетворяющих условию. |
| Аккумулятор | Переменная, в которой накапливается сумма или результат. |
| `Collections` | Утилитный класс с методами сортировки и другими операциями над коллекциями. |

## Теория

Коллекции становятся полезными, когда программа не просто хранит данные, а отвечает на вопросы о них: сколько заказов оплачено, какие товары закончились, есть ли нужный пользователь. Для этого коллекцию обходят циклом и выполняют действие над каждым элементом. В цикле удобно искать совпадение, считать количество и накапливать сумму.

Фильтрация — это отбор элементов по условию. Для простого списка можно создать новый список и добавлять в него только подходящие значения. Важно не удалять элементы из `ArrayList` внутри `for-each`: изменение структуры во время такого обхода может вызвать `ConcurrentModificationException`. Безопасный учебный способ — пройти индексным циклом с конца к началу либо сформировать новый список.

Для сортировки списка можно использовать `Collections.sort` для естественного порядка строк и чисел. Сортировка изменяет исходный список. Для собственной логики порядка есть `list.sort(Comparator...)`, но пока достаточно понимать назначение сортировки и выбирать ясный способ обработки.

## Базовый синтаксис

```java
import java.util.ArrayList;
import java.util.Collections;

ArrayList<Integer> prices = new ArrayList<>();
prices.add(250);
prices.add(120);
prices.add(400);

int total = 0;
for (int price : prices) {
    if (price >= 200) {
        total += price;
    }
}

Collections.sort(prices);
```

Цикл выбирает цены не ниже 200 и добавляет их к сумме. После цикла `Collections.sort` упорядочивает список по возрастанию. Для `Collections` нужен импорт `java.util.Collections`.

## Практические примеры

### Пример 1. Подсчёт заказов по статусу

```java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<String> statuses = new ArrayList<>();
        statuses.add("Оплачен");
        statuses.add("Ожидает оплаты");
        statuses.add("Оплачен");

        int paidCount = 0;
        for (String status : statuses) {
            if (status.equals("Оплачен")) {
                paidCount++;
            }
        }

        System.out.println("Оплачено заказов: " + paidCount);
    }
}
```

### Пример 2. Отбор доступных товаров

```java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<String> products = new ArrayList<>();
        products.add("Клавиатура — в наличии");
        products.add("Мышь — нет в наличии");
        products.add("Монитор — в наличии");

        ArrayList<String> available = new ArrayList<>();
        for (String product : products) {
            if (product.endsWith("в наличии")) {
                available.add(product);
            }
        }

        System.out.println("Доступные товары:");
        for (String product : available) {
            System.out.println(product);
        }
    }
}
```

## Разбор примера

В первом примере `paidCount` — аккумулятор количества: он увеличивается только при совпадении статуса. Для сравнения строк используется `equals`, а не `==`, потому что проверяется содержимое строки.

Во втором примере исходный список не изменяется: подходящие записи копируются в `available`. Это безопасный и понятный способ фильтрации. В реальных программах лучше хранить статус отдельно от названия товара, а не искать его по тексту; здесь формат выбран ради наглядного примера строковых методов.

## Итоги занятия

- обработка строится как проход по элементам с проверкой условия;
- новый список — простой и безопасный способ фильтрации;
- сортировка упорядочивает список, а подсчёт и сумма требуют аккумулятора.
