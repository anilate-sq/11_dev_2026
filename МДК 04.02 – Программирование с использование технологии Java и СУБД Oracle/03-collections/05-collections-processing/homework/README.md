# Домашнее задание: анализ расходов

## Цель

Закрепить обход, фильтрацию, подсчёт и сортировку коллекции.

## Задание

Задан список расходов за месяц. Посчитай общую сумму и количество крупных расходов (не меньше заданного порога). Сформируй отдельный список крупных расходов и отсортируй его по возрастанию.

## Требования

- Исходный список не изменяй при фильтрации.
- Используй цикл и условие для подсчёта и отбора.
- Примени `Collections.sort` к новому списку.

## Что необходимо предоставить

- `Main.java`;
- пример запуска с итоговой суммой и отсортированным списком.
