# Практическая работа № 5

## Тема

Обработка коллекций

## Цель работы

Фильтровать данные, считать агрегаты и сортировать коллекцию.

## Задание

Обработай список оценок студентов. Посчитай количество сдавших (оценка не ниже 3), средний балл и сформируй отдельный список оценок не ниже 4. Отсортируй отобранные оценки и выведи результаты.

## Требования

Список того, что программа должна уметь.

- Используй цикл, условие и отдельный список для фильтрации.
- Рассчитывай среднее по исходному набору, проверив, что он не пуст.
- Отсортируй результат средствами `Collections`.

## Формат результата

Что студент должен предоставить преподавателю.

- исходный код `Main.java`;
- пример запуска и описание фильтрации и вычислений.
