# Блок 3. Коллекции

## Цель блока

Научиться хранить и обрабатывать наборы данных с помощью коллекций Java и выбирать подходящую структуру под задачу.

## Темы

| № | Тема                        | Статус   |
| - | --------------------------- | -------- |
| 1 | [Массивы](01-arrays/README.md)                   | Готово |
| 2 | [ArrayList](02-arraylist/README.md)             | Готово |
| 3 | [Set и HashSet](03-set/README.md)          | Готово |
| 4 | [Map и HashMap](04-map/README.md)        | Готово |
| 5 | [Обработка коллекций](05-collections-processing/README.md) | Готово |

## Результат обучения

После завершения блока студент должен уметь:

- понимать разницу между массивом и списком;
- добавлять, удалять и изменять элементы коллекции;
- обходить коллекции с помощью `for-each`;
- работать с `Set` для хранения уникальных значений;
- использовать `Map` для пар «ключ — значение»;
- выбирать подходящую коллекцию под конкретную задачу;
- решать практические задачи (корзина магазина, база клиентов, учёт товаров).
