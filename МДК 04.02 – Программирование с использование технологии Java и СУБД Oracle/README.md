## Как работать с материалами

1. Откройте нужную тему в таблице и изучите её `README.md`.
2. Разберите примеры из `demo/` и при необходимости запустите их локально.
3. Выполните задание из `practice/README.md` или `homework/README.md`.
4. Сохраните **своё решение** в личном GitHub-репозитории и отправьте ссылку в установленном преподавателем формате.

### Получение материалов

```bash
git clone --branch dev https://github.com/anilate-sq/11_dev_2026.git
```

Откройте склонированную папку в VS Code. Для обновления учебных материалов можно выполнить `git pull` в этой копии, если вы не изменяли её содержимое. Рабочие решения предпочтительно вести отдельно, в личном репозитории.

### Запуск примера

В каталоге с Java-файлом, содержащим метод `main` (например, `demo/Main.java`):

```bash
java Main.java
```

Для этого необходим установленный JDK 11 или новее. Альтернативный запуск:

```bash
javac Main.java
java Main
```

Имя файла в конкретном примере может отличаться от `Main.java`; используйте фактическое имя и инструкции к теме.

### Отправка собственной работы

Команды `git add`, `git commit` и `git push` выполняйте **в каталоге личного репозитория**, который настроен на ваш GitHub:

```bash
git status
git add .
git commit -m "Практика: переменные и типы данных"
git push
```

Проверяйте адрес удалённого репозитория командой `git remote -v` перед отправкой. Не пытайтесь отправлять учебные решения в `anilate-sq/11_dev_2026`.
